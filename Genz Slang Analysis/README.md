# 📊 Gen Z Slang Trends Dashboard (Power BI)

## 📌 Project Overview
This project analyzes **Gen Z slang usage trends** across social media platforms from **2020 to 2025** using **Power BI**.  
The dashboard provides insights into slang popularity, engagement, sentiment, virality, and audience demographics.

The goal of this project is to demonstrate:
- End-to-end data analytics workflow
- Strong Power BI modeling & DAX skills
- Clean, interactive dashboard design
- Business-driven insights from social data

---

## 🧠 Key Business Questions Answered
- How has Gen Z slang usage evolved over time?
- Which platforms generate the highest engagement?
- Which slang terms are most popular and most viral?
- How does sentiment and intensity affect engagement?
- Which age groups drive the most engagement and shares?
- What contexts (humor, criticism, dating, etc.) perform best?

---

## 📂 Dataset Description
The dataset contains simulated Gen Z slang usage data with the following features:

- **Time:** Year, Month, Timestamp  
- **Slang Information:** slang term, category, meaning  
- **Platform Data:** usage platform, origin platform  
- **Audience Data:** age group, region  
- **Engagement Metrics:** likes, shares, comments  
- **Sentiment Metrics:** sentiment type, sentiment score, intensity score  
- **Virality Metrics:** virality score, viral flag  
- **Context:** usage context, lifecycle phase, ironic usage

## 🚀 Key Insights
- Slang usage peaked around 2023–2024
- TikTok dominates engagement among platforms
- Likes form the majority of engagement, followed by comments
- Age group **18–24** drives the highest engagement and shares
- Humor and criticism contexts generate strong interaction
- Higher intensity slang correlates with higher virality
